# ClinSecure Docs
## Sistema Seguro de Gestão de Laudos e Documentos Sensíveis
O ClinSecure Docs é um sistema web desenvolvido para o gerenciamento seguro de documentos sensíveis no ambiente educacional. A plataforma permite armazenar, controlar e compartilhar documentos como laudos médicos, relatórios psicológicos e documentos relacionados à inclusão educacional.
O projeto foi criado para reduzir os riscos do compartilhamento desses arquivos por meios inadequados, oferecendo recursos de segurança, controle de acesso, criptografia e auditoria. Dessa forma, busca garantir maior proteção das informações dos alunos e contribuir para o cumprimento dos princípios da LGPD.

## Objetivo
O principal objetivo do ClinSecure Docs é oferecer uma plataforma segura e centralizada para o armazenamento e gerenciamento de documentos sensíveis de alunos.
O sistema busca garantir que essas informações sejam acessadas somente por usuários autorizados, evitando situações como vazamento de dados, acesso indevido e perda de controle sobre os documentos.
Além disso, a plataforma permite controlar quem pode visualizar cada documento, definir períodos de acesso e registrar as principais operações realizadas no sistema.

## Principais Funcionalidades :

- Cadastro e Gerenciamento de usuário
- Login com autenticação de dois fatores (2FA)
- Upload de documentos
- Criptografia dos documentos
- Controle de acesso por perfil
- Acessos temporários
- Revogação de acessos
- Registro de auditoria
- Recursos relacionados à LGPD
- Recuperação segura de senha
